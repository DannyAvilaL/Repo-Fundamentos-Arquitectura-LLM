## Descripción de las opciones

### 01. Comparador Multi-Proveedor de LLMs con Panel de Costos

Comparación experimental de múltiples proveedores de LLM considerando métricas de **calidad, costo y latencia**, incluyendo al menos una alternativa local mediante Ollama.

[Ir al proyecto →](./Proyecto_01_Comparador_Multi_Proveedor_de_LLMs_con_Panel_de_Costos.md)

### 02. Asistente de Soporte con Grounding y Control de Alucinación

Construcción de un asistente conversacional basado en una fuente de conocimiento verificable, incorporando **grounding y mecanismos de detección de posibles alucinaciones**.

[Ir al proyecto →](./Proyecto_02_Asistente_de_Soporte_con_Grounding_y_Control_de_Alucinacion.md)

### 03. Extractor de Datos Estructurados desde Documentos

Pipeline para transformar documentos de texto libre en información estructurada mediante **Structured Output, Function Calling y validación programática**.

[Ir al proyecto →](./Proyecto_03_Extractor_de_Datos_Estructurados_desde_Documentos.md)

### 04. Gateway LLM Propio con Seguridad de Nivel Producción

Diseño de un gateway centralizado para acceso a LLMs incorporando controles de seguridad basados en **OWASP Top 10 for LLM Applications**.

[Ir al proyecto →](./Proyecto_04_Gateway_LLM_Propio_con_Seguridad_de_Nivel_Produccion.md)

### 05. Agente Conversacional en Google Cloud Agent Platform

Diseño e implementación de un agente conversacional con herramientas propias y despliegue verificable sobre **Google Cloud**.

[Ir al proyecto →](./Proyecto_05_Agente_Conversacional_en_Google_Cloud_Agent_Platform.md)

### 06. Laboratorio de Técnicas de Prompting con Evaluación Cuantitativa

Experimento controlado para comparar diferentes técnicas de prompting utilizando un dataset con **ground truth y métricas cuantitativas**.

[Ir al proyecto →](./Proyecto_06_Laboratorio_de_Tecnicas_de_Prompting_con_Evaluacion_Cuantitativa.md)

### 07. Asistente 100% Local y Privado con Ollama

Construcción de una solución LLM completamente local mediante **Ollama**, diseñada para escenarios donde los datos no pueden salir de la infraestructura de la organización.

[Ir al proyecto →](./Proyecto_07_Asistente_100_Local_y_Privado_con_Ollama.md)

### 08. Framework de Evaluación de Proveedores para un Caso de Negocio

Evaluación de proveedores de LLM combinando criterios **técnicos, económicos, regulatorios y contractuales** para soportar una decisión empresarial.

[Ir al proyecto →](./Proyecto_08_Framework_de_Evaluacion_de_Proveedores_para_un_Caso_de_Negocio.md)

### 09. Pipeline de Moderación y Clasificación de Contenido a Escala

Diseño de un pipeline capaz de procesar contenido a volumen, incorporando **rate limiting, manejo de errores, throughput y métricas operativas**.

[Ir al proyecto →](./Proyecto_09_Pipeline_de_Moderacion_y_Clasificacion_de_Contenido_a_Escala.md)

### 10. Agente sin ADK, Empaquetado en Docker y Desplegado en Cloud Run

Construcción manual de un servicio basado en LLM utilizando **FastAPI, Docker, Google Secret Manager y Cloud Run**, sin utilizar Google ADK.

[Ir al proyecto →](./Proyecto_10_Agente_Sin_ADK_Empaquetado_en_Docker_y_Desplegado_en_Cloud_Run.md)
